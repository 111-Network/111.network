# /demo parity table

Mirrors the node dashboard (`os/interface/ui/src`) **as of 2026-10**. One row per demo file, mapped to the real source file it
ports, with the viewport → container change the port needed (plan §6.5 port rules 1–5) and what differs. View tasks add their
own rows under "Views" as their modules land.

Port rules, as applied: the shell root is an `@container`; `lg:` → `@min-[1024px]:`, `max-lg:` → `@max-[1024px]:` (Tailwind 4's
`@max-[X]` is `width < X`, so `@max-[1024px]` is the exact complement of `@min-[1024px]` and the exact translation of
`max-lg` = `width < 64rem`; `@max-[1023px]` would leave a 1 px gap where neither applies); `dvh` → the shell fills its parent and
its main area is the one scroll container; `matchMedia` → a `ResizeObserver` on the shell root (unless `layout` is forced); the
drawer and its overlay are `absolute` inside the `relative overflow-hidden` root, no body scroll lock, `inert` on the content
column only; the node chip badge is plain device words.
